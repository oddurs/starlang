# ★ StarLang

[![ci](https://github.com/oddurs/starlang/actions/workflows/ci.yml/badge.svg)](https://github.com/oddurs/starlang/actions/workflows/ci.yml)

A zero-dependency **star-topology bidirectional 13-language compiler, WebAssembly 1.0 backend & polyglot time-travel debugger** written in pure Rust (`std` only). Edit a program in **any** spoke language and the other 12 languages update immediately while preserving language-specific idioms via sidecar metadata on the central Hub AST — or compile the Hub AST directly to native `.wasm` bytecode + `.wat` disassembly and scrub through time-travel execution steps across all 13 languages simultaneously.

```text
          Rust (.rs)          Go (.go)
               \                 /
     Zig (.zig) \               / Python (.py)
                 \             /
       C11 (.c) —— ★ Hub AST ★ —— Ruby (.rb)
                 /  /  |   \  \
     C++ (.cpp) /  /   |    \  \ LuaJIT (.lua)
               /  /    |     \  \
  Swift (.swift) Java Wasm Perl TS  Star IR (.star)
```

## Highlights

- **13 Bidirectional Asymmetric Lenses (`get` / `put`)**: Hand-written lexers, recursive-descent parsers, and idiomatic pretty-printers for **Rust**, **Zig 0.16**, **Modern ISO C11**, **Modern C++17**, **Swift 6**, **Modern Java 21**, **Go**, **Python**, **Modern Ruby + RBS**, **LuaJIT + LuaCATS** (0-based ⇄ 1-based indexing bijection), **Modern Perl 5.34** (`use feature 'signatures'`, arrayref/hashref dereferencing & type-directed string vs. numeric operators), **TypeScript**, and **Star S-Expr IR** (`GetPut` verified via property-based fuzzing).
- **Liquid Refinement Types ($\{ \nu : T \mid \phi(\nu) \}$), Constrained Horn-Clause (`CHC`) Solver & Probabilistic MCMC / Shannon Entropy Quantifier (`refinement_prob.rs`)**: Infers **Liquid Refinement Types** over qualifier templates $\mathbb{Q}$, generates and discharges **Constrained Horn Clauses (`CHC`)** ($\Gamma \wedge P(\nu) \implies Q(\nu)$) via fixpoint qualifier elimination, emits **SMT-LIB2 `(set-logic HORN)`** proof scripts, and synthesizes idiomatic **Dependent / Refined / Branded Types across all 13 languages** (`Rust #[repr(transparent)] Refined`, `Zig comptime Refined`, `C11 typedef`, `C++20 template <int64_t Min>`, `Swift 6 @propertyWrapper`, `Java 21 compact record`, `Python PEP 593 Annotated`, `TypeScript __liquid_brand`) — paired with a **Metropolis-Hastings MCMC Probabilistic Sampler & Quantitative Information Flow (`QIF`) Analyzer** that computes posterior moments ($\mathbb{E}[Y], \sigma_Y, [P_{05}, P_{50}, P_{95}]$), **Shannon Entropies** $H(X), H(Y), H(X \mid Y)$, **Mutual Information Leakage** $I(X; Y)$ (in bits), and **Min-Entropy Leakage** $\mathcal{L}_\infty(X \to Y)$.
- **Rank-1 Constraint System (`R1CS`) Zero-Knowledge Circuit Prover, Circom 2.0 Synthesizer & Relational Algebra / Vectorized SQL Optimizer (`zk_sql.rs`)**: Arithmetizes Hub AST functions over the prime field $\mathbb{F}_p$ ($p = 2^{61} - 1$) into bilinear **R1CS constraints** $\langle A_i, \mathbf{w} \rangle \cdot \langle B_i, \mathbf{w} \rangle \equiv \langle C_i, \mathbf{w} \rangle \pmod p$ (`MulGate`, `LinearEq`, `BooleanBit` $b(1-b)=0$, `MuxSelect` $s(t-e)+e$, `RangeBitCheck`), generates deterministic witnesses $\mathbf{w} = (1, \vec{x}_{\text{pub}}, \vec{w}_{\text{priv}}, \vec{y}_{\text{out}})$, proves 100% constraint satisfaction in $\mathbb{F}_p$, and exports **Circom 2.1.6 ZK-SNARK templates** — paired with a **Relational Algebra ($\sigma, \pi, \Gamma$) & Vectorized Columnar SQL Optimizer** that lifts imperative loops into $\Gamma_{\text{agg}}(\pi_{\text{proj}}(\sigma_{\text{pred}}(\text{TableScan}(R))))$, applies **Selection Pushdown** and **Late Materialization** (`Volcano` vs. `1024-row` SIMD Columnar Batch execution), and synthesizes **ANSI SQL CTE queries** plus idiomatic **DataFrame / Stream** queries across all **13 languages** (`Polars`, `Zig ColumnarBatch`, `C11 AVX2`, `C++20 std::views`, `Java Stream`, `Python Pandas`, `TypeScript Arquero`).
- **Lamport Vector-Clock ($\rightarrow$) Actor Concurrency Verifier, 13-Spoke Channel Synthesizer & TLA+ Bounded Model Checker (`dist_actor.rs`)**: Decomposes Hub functions into CSP / Actor pipeline stages (`ProducerStage`, `WorkerStage`, `AggregatorStage`), assigns **Lamport Vector Clocks** $VC(e) \in \mathbb{N}^P$ to send/receive/state-mutation events to prove **Data-Race Freedom (DRF)** and **Wait-For Graph Deadlock Freedom**, lowers functions into idiomatic actors/channels across all **13 languages** (`Rust mpsc::sync_channel`, `Zig BoundedChannel`, `C11 stdatomic`, `C++ jthread`, `Swift 6 actor`, `Java 21 VirtualThread`, `Go chan`, `Python asyncio.Queue`, `Ruby Ractor`, `LuaJIT coroutine`, `Perl 5 Thread::Queue`, `TypeScript MessageChannel`, `Star IR`), and runs an **Explicit-State Bounded Model Checker** over the Kripke structure $\mathcal{M} = (S, S_0, \mathcal{R}, L)$ to verify **Temporal Safety** ($\Box I$), **Temporal Liveness** ($\Box\Diamond\text{Done}$), and **Herlihy-Wing Linearizability** with formal **TLA+ Specification (`MODULE <Fn>_TLA`)** export.
- **Forward-Mode Dual-Number & Reverse-Mode Wengert-Tape Automatic Differentiation (AD), 13-Spoke Gradient Synthesizer & Lipschitz Numerical Stability Auditor (`autodiff.rs`)**: Evaluates Hub functions over **Forward-Mode Dual Numbers** ($a + b\varepsilon, \varepsilon^2 = 0$) and records a **Reverse-Mode Wengert Tape** to backpropagate exact adjoints $\bar{v}_k = \frac{\partial y}{\partial v_k}$ in a single backward sweep, cross-verifying Forward Dual derivatives against Reverse Tape adjoints and central finite-difference probes, synthesizing a 13-spoke differentiable gradient function (`grad_<fn>`) + unit test across all 13 languages, and auditing **Relative Condition Numbers** ($\kappa_f(x) = \|x \nabla f(x) / f(x)\|_\infty$), **Global Lipschitz Bounds** ($L_f = \|\nabla f\|_1$), **Truncating Integer Division Quantization Noise**, and **64-Bit Overflow / Catastrophic Cancellation Hazards**.
- **4-Wide Out-of-Order Superscalar CPU Pipeline, 2-Bit Bimodal Branch Predictor & 8-Way Set-Associative L1D Cache Simulator + Gibbons-Muchnick Critical-Path List Instruction Scheduler (`microarch.rs`)**: Simulates Hub module execution through a **4-wide Out-of-Order Superscalar ROB** (`ALU0..2` 1c, `MUL` 3c, `DIV` 10c, `LSU` 4c, `BRU` 1c), a **64-entry 2-Bit Saturating-Counter Bimodal Branch Predictor** (`StronglyNotTaken` $\leftrightarrow$ `StronglyTaken` with `12c` pipeline flush penalty on mispredict), and a **32 KB 8-Way Set-Associative L1 Data Cache** (`64B` lines, LRU eviction + Next-Line Hardware Stream Prefetcher), paired with a **Gibbons-Muchnick Critical-Path DAG List Instruction Scheduler** that builds the `RAW`/`WAR`/`WAW` Data-Dependence DAG $G = (V, E, \text{lat})$, computes bottom-up critical-path heights $h(u)$, and reorders independent instructions into load/multiply/divide latency shadow slots to eliminate pipeline stall bubbles.
- **Chaitin-Briggs Graph-Coloring & Poletto-Sarkar Linear-Scan Register Allocator + Dual-Target AArch64 / x86_64 Native Assembly & Escape / SROA Optimizer (`regalloc.rs`)**: Lowers Hub functions into a 3-address machine IR, computes exact instruction-level live intervals $[start, end]$ and loop-weighted spill costs, constructs the undirected variable interference graph $G = (V, E)$, performs **Chaitin-Briggs Kempe-stack $K$-coloring** (with conservative move coalescing and stack-frame spill slot allocation `[sp, #offset]` / `[rbp - offset]` when $K$ is constrained) alongside **Poletto-Sarkar Linear Scan**, emits native **AArch64 (ARM64 AAPCS64)** and **x86_64 (System V AMD64)** assembly, and runs **Interprocedural Escape Analysis**, **Scalar Replacement of Aggregates (`SROA`)**, and **Return-Value Optimization (`RVO`)** across all 13 languages.
- **Polyhedral Loop Dependence, Associative Monoid Reduction & 13-Spoke SIMD / Map-Reduce Vectorizer + Floyd-Turing Termination & IPET WCET Prover (`polyhedral.rs`)**: Extracts affine iteration domains ($\mathcal{D} = \{ i \in \mathbb{Z} \mid 0 \le i < N \}$), array read/write access relations ($\mathcal{R}, \mathcal{W}$), and Bernstein loop-carried dependence vectors (distinguishing parallelizable associative monoid reductions `(+, 0)` from guard-read sequential state machines), computes Brent's Theorem work/span ($T_1, T_\infty$) and 4-lane SIMD speedup, and synthesizes idiomatic vectorized/parallel map-reduce kernels across all 13 languages (`@Vector(4, i64)`, `#pragma clang loop vectorize(enable)`, `Int64List.stream().parallel()`, `List::Util::sum0`) — paired with a **Floyd-Turing Well-Founded Ranking Function Termination Prover** ($V(\sigma) \ge 0 \wedge V(\sigma') < V(\sigma)$) and **Implicit Path Enumeration (IPET) Symbolic BCET/WCET Cycle Bound Analyzer**.
- **Equality Saturation E-Graph Superoptimizer & Futamura Partial Evaluator (`egraph.rs`)**: Builds a hashconsed Equivalence Graph (`EGraph`) with Disjoint-Set Union-Find, Congruence Closure (`rebuild`), Constant Lattice Analysis, and 28 algebraic/boolean/relational/intrinsic rewrite rules (`(x + y) - y => x`, `(x * y) + (x * z) => x * (y + z)`, `min(x, max(x, y)) => x`, De Morgan dualities) to extract the provably minimum-gas AST across all 13 languages, paired with a **Futamura 1st-Projection Partial Evaluator** that specializes functions on static constant/enum arguments (`evaluate_quota_spec_i40_burst`), unrolls small constant loops, and verifies **Translation Validation** via the Hub VM and unit test suite.
- **Whitebox Concolic Path Explorer, Boundary-Negation Solver & Denning Lattice Information-Flow Taint Auditor (`concolic.rs`)**: Pairs concrete execution with symbolic path constraint recording ($\Pi = c_1 \wedge \dots \wedge c_k$), systematically solves negated branch boundaries (`a == b` $\leftrightarrow$ `a != b`, `a < b` $\leftrightarrow$ `a >= b`, list lengths & element predicates) to enumerate all feasible execution paths and synthesize path-covering unit tests (`test_concolic_<fn>`) across all 13 languages, while auditing explicit + implicit (`pc_taint`) Denning lattice flows (`Untrusted`, `Confidential`, `Sanitized`, `Clean`), dominating sanitizers, and constant-time side-channel branches.
- **Cytron Static Single Assignment (SSA), $\phi$-Node Placement, Liveness & Hoare-Logic Weakest-Precondition ($WP$) Contract Verifier (`ssa.rs`)**: Computes Immediate Dominators (`idom`), Cytron Dominance Frontiers (`DF`), minimal Iterated Dominance Frontier $\phi$-nodes (`tokens_2 = φ(BB0: tokens_0, BB6: tokens_1)`), backward iterative variable liveness (`live_in` / `live_out`), and Def-Use / Dead-Store chains, and synthesizes & proves Design-by-Contract (`requires`, `loop_invariant`, `ensures`) Hoare triples and Dijkstra Weakest-Precondition Verification Conditions across all 13 languages.
- **Programming-by-Example (PBE) Inductive Program Synthesizer & Dominator Control-Flow Graph (`synth.rs`)**: Synthesizes verified functions + unit tests directly from I/O examples (e.g., `clamp_bonus` or list-folding `sum_above`) via bottom-up enumerative search with **Observational Equivalence Pruning** across all 13 languages, and lowers Hub functions into Basic Blocks with iterative **Dominator Sets**, **Natural Loop Back-Edge** detection, and **Mermaid / Graphviz DOT** CFG export.
- **Counterexample-Guided Automated Program Repair (`repair.rs`) & Bisimulation Verifier**: Localizes failing unit tests or refuted symbolic safety obligations via time-travel backward slicing, searches candidate AST repairs across relational boundaries, accumulators, and safety divisor guards, validates patches against all 4 verification gates (Static Typecheck + Unit Tests + Symbolic Verifier + QuickCheck), and projects unified `- / +` patches across all 13 languages.
- **Asymptotic Big-O, Resource-Gas & 13-Spoke Code-Density Profiler**: Statically classifies loop-nesting and recursion complexity (`O(1)`, `O(N)`, `O(N²)`, `O(2^N)`), computes cyclomatic complexity and heap allocation sites, empirically curve-fits instruction gas across $N \in \{4, 8, 16, 32, 64\}$, and compares logic lines, tokens, and byte density across all 13 languages + `.wasm`.
- **Polyglot Property-Based QuickCheck, Invariant Synthesizer & Minimal Counterexample Shrinker**: Automatically property-tests every function across generated trials, verifies unoptimized-vs-optimized Hub equivalence, discovers algebraic postconditions (including conservation laws such as `result.accepted + result.rejected == len(costs)`), and Delta-Debug shrinks any failing input to a minimal counterexample rendered in all 13 languages.
- **Polyglot Time-Travel Debugger, 13-Spoke Line Mapper & Dynamic Backward Slicer**: Records deterministic step-by-step Hub VM traces, maps every AST statement to its exact 1-based line number across **all 13 languages simultaneously**, and computes dynamic data + control dependency backward causal slices for any variable or assertion.
- **Zero-Dependency WebAssembly 1.0 Binary (`.wasm`) & Text (`.wat`) Compiler**: Hand-encodes W3C WebAssembly 1.0 binary sections (`Type`, `Import`, `Function`, `Memory`, `Global`, `Export`, `Code`, `Data`) with bump-allocated 8-byte-slot structs/lists and structured loop control flow in pure `std` Rust, executing `main` and `test_*` exports in V8's `WebAssembly.instantiate` JIT and directly in the browser.
- **3-Way Cross-Language Semantic AST Merger & Diff**: Reconciles concurrent edits made in **two different languages** (e.g., Python + Zig or Perl + C++) directly on `NodeId`-aligned and LCS-aligned Hub AST nodes + sidecar metadata, projecting the unified result across all 13 languages or reporting pinpoint semantic conflicts.
- **Sidecar Metadata Preservation**: Editing Zig, C11, Python, Ruby, Lua, Perl, Java, or TypeScript preserves Rust borrow slices (`&[T]`, `&str`) and C++ pass-by-value/const-ref choices stored on Hub AST nodes.
- **Hub Symbolic Safety & Dead-Branch Verifier**: Runs Cousot interval abstract interpretation (`[lo, hi]`, disequalities, relational `idx < len(xs)`, loop widening `∇`) paired with concolic Hub VM counterexample probing to prove or refute division-by-zero, list out-of-bounds indexing, inline assertions, and `UNSAT` unreachable branches across all 13 languages.
- **Hub AST Mutation Testing & Auto-Test Hardening**: Mutates boundary conditions and operators directly on the Hub AST, runs polyglot unit tests in-memory against every mutant, and automatically synthesizes missing boundary assertions (`test_mutation_hardened`) across all 13 languages at once.
- **Sub-Millisecond Hub VM, Live Unit Tests & AST Coverage Tracer**: Executes `main()` and polyglot unit tests on every keystroke, reporting statement-level AST coverage %, function hotspots, call-graph traces, and uncovered dead branches.
- **Cross-Language Semantic Refactoring & Optimizer**: Scope- and type-directed symbol renaming plus constant folding and dead-branch pruning across all 13 spokes simultaneously.
- **14-Engine Parallel Differential Verification**: Compiles and runs native toolchains concurrently (`Hub VM`, `Wasm (V8 JIT)`, `rustc`, `zig run -lc`, `clang -std=c11`, `clang++` with cached STL PCH, `swiftc`, `javac`/`java`, `go run`, `python3`, `ruby`, `luajit`, `perl`, `node`) and verifies byte-for-byte identical `stdout`.

```bash
cargo run -- trace                # Inspect Hub AST statement coverage %, hotspots & call trace
cargo run -- test path/to/prog.pl # Run polyglot unit tests in sub-ms via Hub VM
cargo run -- fuzz 100             # Property-based 13-spoke GetPut lens fuzzer (1,300 round-trips)
cargo test                        # Full integration + 14-engine differential test suite
```
